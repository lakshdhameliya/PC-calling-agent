                    FRONTBIT LINK - AI PHONE VOICE AGENT
                     (આખા ફોલ્ડરમાંથી ચલાવવાની સંપૂર્ણ માર્ગદર્શિકા)
================================================================================

આ ફોલ્ડર ("C:\Frontbit Link") માં Frontbit Link એપ અને AI વોઇસ એજન્ટ બંને એક સાથે 
સંપૂર્ણપણે સેટ થઈ ગયા છે. હવે તમારે કોઈ બીજાને આ પ્રોજેક્ટ આપવો હોય, તો માત્ર આ આખું 
"Frontbit Link" ફોલ્ડર જ આપવાનું રહેશે!

--------------------------------------------------------------------------------
🚀 આ કેવી રીતે કામ કરે છે? (માત્ર ૧ જ ફાઇલ પર ક્લિક કરવાનું!)
--------------------------------------------------------------------------------
👉 "1 - START EVERYTHING (Frontbit Link + Voice Bot).cmd"

૧. જો કોઈ નવું PC હશે (જ્યાં કશું જ ઇન્સ્ટોલ નથી):
   - સ્ક્રીન પર એક સુંદર અને પ્રોફેશનલ ડાર્ક-થીમ વિન્ડો ખૂલશે.
   - તેમાં પ્રોગ્રેસ બાર સાથે %, ડાઉનલોડ થયેલા MB (દા.ત. 14.5 MB / 24.2 MB) 
     અને નેટવર્ક સ્પીડ (MB/s) લાઈવ દેખાશે.
   - બધું જ આપોઆપ સેટ થઈ જશે (Python, AI મોડેલ્સ અને લાઈબ્રેરીઓ).
   - Windows Start Menu અને Desktop પર "Frontbit Link" નો શોર્ટકટ પણ આપોઆપ બની જશે.
   - સેટઅપ પૂરું થતાં જ Frontbit Link એપ અને AI Voice Bot બંને આપોઆપ ખૂલી જશે!

૨. બીજી વાર અથવા રોજેરોજ ચલાવતી વખતે:
   - જે વસ્તુઓ PC માં પહેલેથી છે તે ફરીથી ડાઉનલોડ થશે નહીં!
   - સીધું જ ૧ સેકન્ડમાં Frontbit Link અને Voice Bot ચાલુ થઈ જશે!
   - તમે કીબોર્ડ પરથી Windows Key દબાવીને "frontbit" ટાઈપ કરશો તો પણ સીધું ખૂલી જશે!

--------------------------------------------------------------------------------
📁 ફોલ્ડરમાં રહેલી મુખ્ય ફાઈલો:
--------------------------------------------------------------------------------
૧. "1 - START EVERYTHING (Frontbit Link + Voice Bot).cmd"
   - બધું જ ૧ ક્લિકમાં ચાલુ કરવા માટેનો ઓટો-ઇન્સ્ટોલર અને લોન્ચર.

૨. "Frontbit_Link_Android_Companion.apk"
   - મોબાઇલ ફોનમાં ઇન્સ્ટોલ કરવા માટેની એપ (આ ફોન PC સાથે કનેક્ટ કરવા માટે છે).

૩. "VoiceAgent\" ફોલ્ડર:
   - આ ફોલ્ડરમાં બોટના બધા જ કોડ, મોડેલ્સ અને સેટિંગ્સ છે:
     * voice_settings.json : અવાજના સેટિંગ્સ (Pure HD Swara/Dhwani).
     * greeting.json       : ફોન ઉપાડતી વખતે બોલાતો આવકાર મેસેજ.
     * bestzoneFAQ.csv     : પૂછાતા સવાલો અને જવાબોનો ડેટાબેઝ.
